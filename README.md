# SwiftShop 🛒⚡

Quick-commerce grocery storefront — React + Vite + Tailwind CSS. Dark, tech-forward theme
built around the "delivered in minutes" thesis: live countdown hero, flash-deal timers,
category browsing, product detail, cart, and a mock checkout flow.

## Tech stack
- React 18 + React Router 6
- Vite (build tool)
- Tailwind CSS (utility styling, custom theme tokens)
- lucide-react (icons)
- Context API for cart state (no external state library needed)

## Getting started

```bash
npm install
npm run dev
```

App runs at `http://localhost:5173` by default.

To build for production:
```bash
npm run build
npm run preview
```
